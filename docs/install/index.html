N Player

A Jellyfin client for the server you run yourself.

Download the APK

Android 8.0 or newer · debug build

  1. Tap Download above — the file lands in your Downloads.
  2. Open it, and allow your browser to install unknown apps when Android asks.
  3. Install, then open N Player and sign in to your server.
Android warned me during install

Releases are debug-signed, so Play Protect reports an unrecognised app. That is a statement about provenance, not a detected threat. Choose Install anyway, or build from source if you would rather not trust the binary.

Where do I get a server URL?

N Player is a client, not a service — it talks to a Jellyfin server you operate. See Connecting to your server for the address to use on a LAN, behind a proxy, or in Docker.
