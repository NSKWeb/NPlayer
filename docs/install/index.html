  1. Tap Download above — the file lands in your Downloads.
  2. Open it, and allow your browser to install unknown apps when Android asks.
  3. Install, open N Player, and tap Allow access so it can read your media. That is the only setup step.
Android warned me during install

Releases are debug-signed, so Play Protect reports an unrecognised app. That is a statement about provenance, not a detected threat. Choose Install anyway, or build from source if you would rather not trust the binary.

Why does it ask for my media?

N Player reads your video and audio from Android's own media library, so it needs the read-media permission to list and play them. It is read-only: the app cannot change or delete your files, and it has no network access at all. See The media permission for the exact grants on each Android version.

My files are not showing up

N Player lists what Android's MediaStore knows about. If a file is missing, give the system a moment to index it after copying it over, or tap Scan again on the Home screen. Files in app-private folders that MediaStore does not expose will not appear.
